# 📹 Funkey — Random Video Chat

Meet strangers around the world through random live video calls. Hit connect and you're instantly in a 1-on-1 video chat — fast, spontaneous, and fun.

## Features

- 🎲 Random 1-on-1 video matching
- 📹 Live camera + microphone calls (WebRTC)
- ⚡ Instant connect, minimal friction
- 🛡️ Report & block controls for safety

## Tech Stack

- Next.js + TypeScript
- WebRTC for real-time video
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start chatting.
